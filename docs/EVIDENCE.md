# Evidence

Sources for every hardware constant in this repository. `pixelios` refers to
the local reverse-engineering tree used to derive the original bluejay
bring-up (`soc/google/gs101`, `device/google/bluejay`).

## UFS

| Fact | Value | Source |
|---|---|---|
| UFS HCI base | `0x14700000` | measured bluejay probe, `soc/google/gs101/soc.json` |
| vendor HCI window | `+0x1100` | pixelios `ufsinit.c` (`VS`) |
| PHY/PMA window | `+0x4000` | pixelios `ufsinit.c` (`PMA`) |
| UNIPRO window | `+0x80000` | pixelios `ufsinit.c` (`UNIPRO`) |
| MPHY isolation bypass | PMU `0x17460000` + `0x3EC8` bit 0 | pixelios `ufsinit.c` step 2-4 |
| HSI1 I/O coherency | SYSREG `0x14420000` + `0x710` bits 0..1 | pixelios `ufsinit.c` step 2-4 |
| MCLK period register | UNIPRO `+0x44`, `16000000000 / mclk` | pixelios `ufsinit.c` step 12 |
| Pre-init PHY table | 65 rows | Linux `phy-gs101-ufs.c` via `docs/07-gs101-ufs-bringup.md` Appendix A |
| Pre/post HS power tables | 2 and 3 rows | same |
| HS mode | HS-G4, Series B (2), 2 lanes, `UFS_RATE=2` | pixelios step 22 |
| Link-startup retry | 3 attempts | pixelios `ufs_cold_init()` |

The PHY rows are generated by pixelios `tools/gen-ufsphy-tables.py`; the
generated `UfsPhyTables.h` here is a mechanical retype (`uint8_t`/`uint16_t`
to `UINT8`/`UINT16`), values unchanged.

## Deliberate non-facts

- The GS101 chip-id/revision *register* is not known. `GS101ChipInfoDxe`
  returns `0x8015` for `GetId` (the ADT identifier) and `0.0` for
  `GetRevision`. No register is read.
- PMIC, GPIO, DWC3 and touch register maps are not included: none of them is
  implemented.
- The FD base (`0xF9800000`), stack (`0xF9A00000`) and DXE heap (`0xFB600000`)
  are addresses chosen inside measured free holes, not addresses reported by
  ABL. See `docs/PLAN.md`.
